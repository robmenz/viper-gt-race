# Viper GT Race 2003

Gioco di corse scritto in C++ nel 2003 per l'esame di Elementi di Informatica
(premio per il miglior gioco del corso). Questa è la versione web del 2026:
stessa logica dell'originale, giocabile nel browser e installabile sul telefono.

**Gioca:** https://robmenz.github.io/viper-gt-race/

## Comandi
- Frecce: guida (↑ accelera, ↓ frena) · Spazio: clacson · M/N: musica · P: pausa
- Da telefono: pulsanti a schermo; ★ apre segreti e trucchi

## File
| File | A cosa serve |
|---|---|
| index.html | Il gioco completo (grafica e suoni inclusi) |
| manifest.webmanifest | Nome e icone per installarlo come app |
| sw.js | Lo rende installabile e giocabile offline |
| icon-*.png, apple-touch-icon.png, favicon.png | Icone |
| og-image.png | Immagine di anteprima per LinkedIn |
